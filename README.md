
# TASKS CONTROL — Planificador de Tareas

## 1. Descripción del proyecto
**TASKS CONTROL** es una plataforma web intuitiva diseñada para simplificar la gestión diaria de pendientes. Permite registrar, clasificar y dar seguimiento a proyectos en tiempo real, optimizando el tiempo y mejorando la productividad mediante una interfaz ágil y un sistema de validación inteligente.
